우리 반 일정
앱처럼 쓰는 법

수행평가, 시험, 제출물을 한눈에. 홈 화면에 추가하면 주소창 없이 앱처럼 열려요.

주소
class-schedule-smoky.vercel.app

먼저 이 주소를 브라우저에서 열어 주세요. 아래 순서는 그 다음입니다.

아이폰 Safari

반드시 사파리로 열어야 합니다. 크롬이나 카카오톡 안에서 열면 '홈 화면에 추가'가 안 보여요.

1

아래 가운데 공유 버튼을 누르세요

네모에 위 화살표가 있는 아이콘이에요

2

메뉴를 위로 넘겨서 홈 화면에 추가를 누르세요

목록 중간쯤에 있어서 스크롤해야 보여요

3

오른쪽 위 추가를 누르면 끝

홈 화면에 아이콘이 생겨요

안드로이드 Chrome

삼성 인터넷을 쓴다면 아래 […] 버튼 → '현재 페이지 추가' → '홈 화면'으로 조금 다릅니다.

1

오른쪽 위 점 세 개를 누르세요

주소창 맨 오른쪽에 있어요

2

목록에서 홈 화면에 추가를 누르세요

'앱 설치'라고 나오는 경우도 있어요. 같은 기능입니다

3

추가를 누르면 끝

기종에 따라 '설치'로 보일 수 있어요

홈 화면에 추가하면 뭐가 좋나요

  • 주소를 매번 안 쳐도 아이콘 한 번으로 열려요
  • 주소창 없이 전체 화면으로 떠서 앱처럼 보여요
  • 열 때마다 최신 일정을 받아오니 새로고침할 필요가 없어요

그냥 브라우저 즐겨찾기로 써도 내용은 똑같아요!

'홈 화면에 추가'가 안 보여요
아이폰은 사파리, 안드로이드는 크롬으로 열어야 나와요. 카카오톡에서 링크를 바로 누르면 카톡 안 브라우저로 열려서 안 보입니다. 오른쪽 아래 메뉴에서 '다른 브라우저로 열기'를 눌러 주세요.
일정을 제가 추가할 수 있나요
아니요. 일정 등록은 반장만 할 수 있어요. 빠진 일정이 있으면 알려 주세요.
새 일정이 안 보여요
앱을 완전히 껐다가 다시 열어 보세요. 이미 열어 둔 상태라면 화면이 자동으로 바뀌지는 않아요.
알림이 오나요
앱 자체에서 울리는 알림은 없어요. 중요한 일정은 단톡방에 따로 공지할게요.
궁금한 건 반장에게 물어보세요
